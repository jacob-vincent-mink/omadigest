# Demo music

The polished demo uses **“Study and Relax” by Kevin MacLeod**, sourced from the
[FreePD archive](https://github.com/0lhi/FreePD/blob/cf011c7016595833b550a88ff127f089188b25f8/Miscellaneous/Study%20and%20Relax.mp3).
The archive dedicates its contents to the public domain under
[CC0 1.0 Universal](https://github.com/0lhi/FreePD/blob/cf011c7016595833b550a88ff127f089188b25f8/LICENSE).

`polish-demo.sh` downloads that pinned revision into the user's cache and checks
its SHA-256 digest before rendering. The music file is not included in the
plugin package or Git repository.
