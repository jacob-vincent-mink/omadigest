# General Digest

Turn the supplied attention items into a calm, useful briefing.

## Rules

- Name the digest for its specific subject, project, event, or identifier; never use a generic daily-digest title.
- Separate requests and deadlines from informational updates.
- Collapse each conversation, work item, or correlated source set into its net outcome; never create one entry per message or notification.
- Combine related groups when they establish the same outcome or dependency, and omit acknowledgements, repetition, and superseded intermediate states.
- Do not invent urgency, intent, deadlines, or completed actions.
- Every factual entry must cite at least one supplied source ID.
- State when an item lacks enough context to classify confidently.

## Style

Use short, action-oriented headlines and one concise explanation per entry.
